2怎麼對帳

  1. 在 MS 點書籤、選好這批：面板出現後（標題顯示當前平台，跟著右上角選的平台），點類別（第三方入款／出款、一般入款／出款）；需要的話用「篩銀行」篩出某幣種／銀行，確認統計無誤。
  2. 按 📌 記錄這批以對帳：面板會顯示一組綠色 6 碼核對碼，資料暫存雲端、5 分鐘內有效（不用複製、不用開放剪貼簿）。
  3. 切到對應系統點同一書籤：第三方→管理系統；一般→虛擬幣系統。跳出輸入框，貼上那 6 碼 → 按核對（或 Enter）。
  4. 看結果：上方筆數／金額是否一致；紅色「只有 MS 有」＝要追的漏單；明細左 MS、右對方並排對照。跨日補撈到的會標日期。
提醒：核對碼 5 分鐘內有效、可重複核對；過期就回 MS 重按「記錄這批」拿新碼。更新版本時，三個系統的書籤都要重貼一次原始碼（只重新整理網頁沒用）。詳細操作、四種核對邏輯與疑難排解見同壓縮檔內的「使用說明.html」。

4核對結果怎麼看

  • 最上方統計：筆數／金額／(一般核對還有)虛擬幣顆數，標 ✓ 一致 或 ✗ 不一致。一般核對以 MS 這批 為基準，「虛(配)」只算已配對。
  • 🔴 只有 MS 有：MS 說成功、對方找不到 —— 要優先追的漏單。
  • 🟡 只有對方系統有：對方有、你這批 MS 沒記到，通常免處理、僅供查漏參考(一般核對只列帳日 3 點後的)。
  • 明細(左右對照)：每筆一列，左 MS、右對方；一般入款「補配」筆淡黃底、跨日補撈到的標充值日期(如 🕐9/10)。
看的順序：先看上方有沒有 ✗ → 有就看紅色「只有 MS 有」去追 → 黃色通常免管 → 明細左右對照做最後核對。

虛擬幣幣種對照(currencyType)：TRC-USDT=101、BSC-USDT=201、ERC-USDT=1、TON=301、SOL=401。

成功狀態：虛擬幣入款 depositStatus=2、虛擬幣出款 payStatus=3、管理系統出款(自動) status=3。

時間／帳日：帳日切點每天凌晨 3:00；一般核對抓取以 MS 這批時間前後各 6 小時，時間配對容差 ±3 小時內取最近，超過用雙金額補配；配不上會逐日往前補撈最多 7 天。

6疑難排解

  • 輸入核對碼卻「讀不到」：① 書籤是不是最新版(重貼原始碼)②碼過期了(5 分鐘，回 MS 重記)③碼打錯。
  • 「只有對方系統有」很多筆：正常，是同商戶同幣種、你這批 MS 沒記到的，僅參考。
  • 某平台一般入款全配不上：多半該幣 currencyType 沒對到(系統新增鏈別)，回報一筆該幣資料即可加對照。
  • MS 按記錄跳「上傳雲端失敗」：網路或雲端暫時不通，重按一次。
更新版本時，三個系統的書籤都要重貼一次原始碼(只重新整理網頁沒用)。回報問題附上：哪個系統、哪個類別、畫面截圖，以及 F12 → Console 的紅色錯誤字，最容易定位。
